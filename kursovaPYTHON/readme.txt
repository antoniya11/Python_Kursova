PROJECT: Library Management System

Описание:
Това е проста система за управление на библиотека,
разработена с Python.

Функционалности:
1. Създаване на книги.
2. Показване на всички книги.
3. Филтриране на книги преди 2000 година.
4. Сортиране на книгите по година.

Използване:
1. Инсталирайте Python.
2. Отворете проекта.
3. Стартирайте main.py.

Използвани технологии:
- Python
- Вградени библиотеки на Python
